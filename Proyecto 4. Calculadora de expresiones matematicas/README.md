# Proyecto 4. Calculadora de expresiones matematicas

Este seria uno de los proyectos mas importantes de la unidad 
el programa Debera convertir expresiones
inflija -> postfija -> Evaluacion 

por ejemplo: (5 + 3) * 2
convertir:
5 3 + 2*
y obtener:
Resultado = 16
El temario propone especificamente desarrollar una clase calculadora que convierta expresiones infijas a posfijas 
y posteriormente las evalue utilizando pilas
**Funciones**

* Validar expresion
* Convertir infijas -> postfija
* Evaluar expresion postfija
* Manejar parentesis 
* Manejar operadores

+, -, *, /, %, ^
Detectar errores matematicas 
Ejemplo
Entrada 
(10 + 5) * 2 - 8
